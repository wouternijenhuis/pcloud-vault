# Code of conduct

We want pCloud Vault to be a welcoming project for everyone, whatever their background, identity or experience.

**Expected:**

- being kind, patient and respectful;
- assuming good intent;
- giving and accepting constructive feedback;
- focusing on what is best for users and the community.

**Not acceptable:**

- harassment, insults or discrimination;
- sexualized language or imagery;
- personal or political attacks;
- publishing others' private information;
- any conduct that would be inappropriate in a professional setting.

Maintainers may edit or remove contributions, and may restrict participation, when this code is not respected. Report problems privately to the maintainers through the contact option on the maintainer's GitHub profile, or through a private security advisory if it involves a vulnerability. Reports are handled confidentially.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
